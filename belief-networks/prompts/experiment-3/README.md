# Experiment 3: new information and pressure over rounds, and eight agents on a social network (ICE enforcement)

- The list on immigration enforcement from the second domain study: forty statements generated by Fable 5.1 from eighteen articles, with forty negations generated by Sonnet, given as eighty statements.
- A: one model at a time over five rounds, without the articles. In each round one item is added to the prompt: nothing, an article from the same side as the focal statement, an article from the other side, a report stating the opposite, or a request to reconsider without evidence. Round 0 is the model’s network from the second domain study.
- B: eight model instances (three first given the left-leaning set, three the right-leaning set, two the balanced set) on a complete, ring or two-community network, for eight rounds, each given its neighbours’ ratings from the previous round.
- Claude Haiku 4.5 and Sonnet 5.5 through the API, with temperature and reasoning variants where the API allowed them.

Requests were sent from 11 October 2026, 16:56 to 17:24 (Pacific time).
