# Beliefs generated for five more topics

Can the models under test generate the belief set from the articles, following the ontology, with checks strict enough to make the set rigorous?

- The procedure of an earlier run (“Beliefs generated by the models”, 29 September), applied to five more topics: tariffs and prices, congestion pricing, GLP-1 drugs, AI and learning, and nuclear revival.
- For each topic, ten news articles in date order, each cut to its first 260 words.
- Claude Haiku 4.5 and Sonnet 5, through the Claude Code command line, each generated claims of one type per request (factual, interpretive or evaluative), four times.
- GPT-5.4 mini checked each claim’s kind, form and neutrality, and whether it is faithful to its article. Sonnet 5 grouped the claims that say the same thing.
- Through the command line, Claude Code’s own system prompt comes first and the study’s system prompt is appended.

Requests were sent from 29 September 2026, 12:35 to 12:40 (Pacific time).
