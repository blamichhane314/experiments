# Calibration: wording, paraphrase and negation, structure, article effects, size

Measurements every later experiment needs, independent of its design.

- Twenty-four statements per topic, three of each kind, taken from the pooled claims of the generation runs; seven topics.
- A: nine wordings of the stance request. B: each statement replaced by a paraphrase or by its negation. C: related pairs under different definitions of a relation (fit or clash, evidence, cause). D: all ten articles, each one left out, and each one alone. E1 and E2: about a hundred statements of one topic, and the 168 statements of the seven topics together. S: one statement per request. P: the update request with neighbours who share the agent’s own state, or with none.
- Each module was run with no articles and with all ten articles, where that applies.
- Claude Haiku 4.5, Sonnet 5 and Opus 4.5 through the Claude Code command line; Opus on two topics. Claude Code’s own system prompt comes first and the study’s system prompt is appended.

Requests were sent from 29 September 2026, 12:25 to 14:37 (Pacific time).
